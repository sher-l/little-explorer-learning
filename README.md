# 小小探险家

独立项目站，仓库名 `little-explorer-learning`，不会替换账户的个人博客仓库。网站全部内容在 `public/`；完整文件及 SHA-256 清单在 `public/release-manifest.json`。

包含五区 25 关、125 个主线收集点、五张完整绘画迷宫、三种角色（小兔、小猫、小狗）、可重玩进度、题库和按需加载的本地语音模型。没有本机录音、合成 MP3、存档、开发日志、密钥或原概念稿。

本仓库只包含已检查的公开内容。在该仓库的 Pages 设置中选 GitHub Actions，手动运行 `Publish reviewed learning game` 工作流。它不会在 push 或定时任务时自动发布。官方动作固定到核查时的提交，不上传 public/ 之外的材料。部署结果以仓库 Actions 和 Pages 状态为准。

打开站点后，家长可阅读 [使用、隐私和素材说明](public/about.html)。游戏和模型的代码、许可各自独立，见 [语音依赖清单](public/licenses/browser-asr/ATTRIBUTION.md)。页面代码与生成美术未另外授予开源许可。

首次语音模型准备约 241 MiB，识别在浏览器本地执行；不等同发音评分。网页朗读仍依赖设备的本地中英文声音，未保证跨设备音色或儿童语音准确性。

迁移：在原本机游戏暂停菜单导出成长记录，在新站家长工具中导入。不会自动跨域复制存档。项目站使用 `little-explorer-learning.*` 的独立键；不要改成博客或本机游戏的存储键。题库包如曾自行升级，需在新站再次安装同一份包。
